# Purple Comunicação — Fase 1

Starter em Vue 3 + Vite + TypeScript para um site institucional com blog simples em JSON.

## Rodando o projeto

```bash
npm install
npm run dev
```

## O que já vem pronto

- Home
- Sobre
- Contato
- Blog com busca simples
- Página interna de post
- Conteúdo institucional em `src/data/site.json`
- Posts do blog em `src/data/posts.json`
